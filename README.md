# ΔT Constraints from Two Historical Solar Eclipses

**Events**:  
- AD 761 total solar eclipse (Chang’an, Tang dynasty)  
- AD 1361 near‑central eclipse (Songjiang, Yuan dynasty)

**Method**:  
- Ephemeris: JPL DE441  
- Computation: Skyfield (Python)  
- ΔT scan: 1000–3500 s (761) & 500–2000 s (1361)  
- UT scan: full day or optimized window

**Key Results**:  
- 761: ΔT ∈ [1670, 3209] s (totality)  
- 1361: ΔT ∈ [545, 1801] s (totality)
